# ANUSHRAWAN (अनुश्रवण) — Bharat Fleet Cargo Security & Telemetry

> **अनुश्रवण (Anushrawan)**: Continuous auditory and sensory surveillance / real-time monitoring.

Real-time IoT load-sensor cargo theft detection and highway fleet telemetry engineered for Indian logistics corridors, FASTag networks, and national highways.

## Key Capabilities

- **अभेद्य सुरक्षा (Impermeable Cargo Protection)** — Multi-point load cell sensors detect sudden transit weight drops within 1.2 seconds.
- **NavIC & GPS Dual Satellite Tracking** — Live telemetry calibrated for Indian highway corridors (NH-48, NH-44, NH-19, NE-4 Expressway).
- **FASTag & E-Way Bill Aligned** — Continuous weight audit against consignment manifest baselines.
- **Corridor Visualization** — Traversed vs planned route with milestone and toll-gate proximity pins.
- **Zero False-Alarm Dynamic Filtering** — Filter out ghat section tilt, speed-breaker shocks, and rough terrain vibrations.
- **Unified Fleet Ops Console** — Live alerts, load stability charts, and multi-corridor fleet analytics.
