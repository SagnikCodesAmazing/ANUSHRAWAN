# ANUSHRAWAN (अनुश्रवण)

Real-time load-sensor cargo theft detection and highway fleet telemetry for Bharat logistics.
Hardware Architecture:
- Load Cell: Cargo weight measuring & theft detection
- TPMS: Axle-wise tire pressure and thermal monitoring
- GSM: Cellular telemetry communication & command channel
- Solenoid Valve: Fuel pipe control & remote vehicle immobilization for corrupt drivers
